# INTRODUCCIÓN
El siguiente proyecto esta diseñado e implementado para un sistemas experto inteligente basasdo en la lógica computacional y automatización robótica de procesos, orientado al diagnóstico médico preliminar, MediLogic permite a los usuarios ingresar síntomas, enfermedades crónicas y alergias a medicamentos para recibir un informe con posibles enferemdades, porcentaje de afinidad y tratamiento sugerido.

Este proyecto busca potenciar el razonamiento computacional y que el sistema sirva como herramienta de orientación médica, simulando el razonamiento de un especialista de salud a través de programcación lógica, tomando en cuenta que este diagnóstico no sustituye la consulta médica profesional.
